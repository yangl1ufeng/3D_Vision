# 3D Vision

三维视觉课程项目仓库。当前项目方向为：**面向杂乱桌面分拣的多视角三维抓取规划与避碰系统**。

项目流程包括目标分割、三维点云处理、抓取姿态生成、碰撞检查和结果记录，后续接入 RGB-D 相机及多视角融合。

## 仓库范围

仓库用于保存自编源码、配置、测试、报告，以及当前抓取项目的准备实验记录。

当前项目入口：[三维桌面抓取](projects/graspgen_feasibility/README.md)。准备实验1–6的代码、图表、结果和失败样例已归档；上传范围与复现依赖见 [归档说明](projects/graspgen_feasibility/ARCHIVE.md)，最新结论见 [鲁棒性与规模压力测试](projects/graspgen_feasibility/ROBUSTNESS_STRESS_RESULTS.md)。

课程资料 `理论课/`、`实验课/` 和 `Shares/`，以及下载的环境、第三方代码、原始下载数据集、模型权重、论文文件，通过 `.gitignore` 排除。当前抓取项目的 `runs/`（不含运行日志）和用于实验的规范化官方样例输入为明确保留的例外。

第三方算法、代码、模型和数据的许可按各自项目要求处理。

## 官方场景实测

输入：官方 `real_scene_pc/1745619598_467125.json`，1280×720 图像，目标为桌面蓝碗。SAM2 框来自官方目标点与图像像素的对应，模拟用户选择；这不是独立目标检测评价。

默认配置：Robotiq-2F-140，PointNet++ 官方权重，100 候选，10 步扩散，评分阈值 0.8。目标点按官方 L1 邻居距离规则去噪；背景最多 8192 点、夹爪表面 2000 点、碰撞距离 20mm、批量 4。种子 1000，表面抽样种子 1001。

| 项目 | 结果 |
|---|---:|
| 分割掩码像素 | 10087 |
| 有效目标点 | 4894 |
| 去噪后模型输入点 | 4739 |
| 完整背景点 | 428809 |
| 碰撞输入背景点 | 8192 |
| 原始候选 | 100 |
| 评分及姿态检查通过 | 53 |
| 低分排除 | 47 |
| 场景碰撞排除 | 46 |
| 当前筛选保留 | 7 |

保留候选按评分排序的 ID：80、85、64、67、83、68、33。所有 100 个保存姿态均为有限数值，旋转正交且行列式为 +1。

此前单场景集成脚本保留 8 个候选；本次为 7 个。离线核心把点云和夹爪表面抽样的随机源分离并固定，改变了碰撞使用的具体采样点。此差异不能解释为抓取生成方法的准确率下降，也不能把任一数量解释为真实成功率。后续应通过独立参考几何评价碰撞漏检和误拒绝。

## 性能记录

设备：RTX 4070 Laptop，8188 MiB 显存；Windows，Python 3.12.6，PyTorch 2.11.0+cu128。两次均由新进程启动、重新加载模型，未在该进程提前预热。

| 项目 | 首次转换并运行 | 复用输入转换后运行 |
|---|---:|---:|
| 计算阶段合计（秒） | 1.845 | 1.414 |
| SAM2 模型加载（秒） | 5.680 | 3.189 |
| GraspGen 模型加载（秒） | 8.950 | 9.199 |
| 入口壁钟时间（秒） | 23.668 | 18.497 |
| CUDA 已分配显存峰值（MiB） | 1686.9 | 1686.9 |
| CUDA 保留显存峰值（MiB） | 2182.0 | 2182.0 |
| NVML 整卡采样峰值（MiB） | 3850.2 | 3787.9 |

第二次计算阶段：分割 0.779 秒，点云 0.153 秒，抓取生成 0.374 秒，评分筛选 0.001 秒，碰撞 0.106 秒。

计算阶段不含素材读取、模型加载、来源 SHA256 校验与结果导出。壁钟时间从参数解析完成后开始，不含 Python 启动及模块导入、最终汇总 JSON 写入和控制台输出。NVML 为整卡 20ms 采样，包含桌面及其他进程；这是两次功能验收测量，不是统计充分的吞吐量基准。历史 30 次硬件基准见 `RESULTS.md`。

## 检查结果

- 16 项标准库 `unittest` 检查全部通过：单位/尺度、旋转反射及齐次行、毫米深度反投影、相机/世界变换、深度与 XYZ 对应、负世界 z、缺少标定、像素对齐/尺寸、无效/空掩码、空背景、异常诊断和历史结果保护、候选原因/排名/导出。
- 实际 GPU 碰撞函数的已知几何检查通过：旋转平移后的表面点与障碍重合时排除；远离时保留；距障碍 1cm、阈值 2cm 时排除。
- 两次 JSON/CSV/NPZ 的完整记录检查通过，姿态与评分最大差值均为 0；所有检查数组完全一致。本结论限于本机同配置，不保证跨 GPU 或软件版本逐位一致。
- 分割叠加图已人工查看，目标区域覆盖桌面蓝碗。

本机输出目录（模型、数据和结果仍遵循 `.gitignore`，未上传）：

- `runs/offline/stage1_validation/`：首次运行；
- `runs/offline/stage1_repeat/`：更新后的规范配置与重复运行；
- `runs/offline/stage1_verification.json`：结果一致性与记录完整性检查。
